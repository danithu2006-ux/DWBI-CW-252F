GAHDSE-018

A-Level Result Analysis This project analyzes A-Level examination performance in Sri Lanka, focusing on Z-score distributions and district rankings across academic streams. Key Insights Stream Performance: Physical Science achieved the highest pass rate (78.7%), followed by Biological Science (77.4%). Competitive Analysis: Visualized the correlation between top district ranks and average Z-scores. Data Processing: Cleaned and normalized Z-score/Rank data from a 330k+ record dataset using Pandas.
